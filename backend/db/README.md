# Base de datos

- `schema.sql`: crea la base de datos y las tablas siguiendo el DER de EcoObra, incluyendo las extensiones necesarias para el contrato actual de la API.
- `seed.sql`: carga datos semilla útiles para la demo: 8 productos, 3 bodegas, 3 proveedores, 15 órdenes, 13 lotes y 24 movimientos, además de clientes, trabajadores y una factura.

Ejecutar primero `schema.sql` y luego `seed.sql`.
